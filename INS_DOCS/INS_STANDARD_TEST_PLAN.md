# INS 标准化确认测试计划

更新时间：2026-07-14

## 当前判断

当前手推测试结果说明第一版 INS 已经可用：

- 直线约 100cm，误差约 5cm。考虑 100cm 本身不一定标准、且是手推测试，这个结果可以接受，但还不能作为精确标定依据。
- 约 60cm 正方形回到原点，X 误差约 2cm 到 8cm，Y 误差约 0.5cm 到 2cm，偏航角几乎无误差，说明当前轮速里程计 + IMU yaw 融合方向是对的。
- 结论：不需要大范围返工；先做一轮更标准的确认测试，通过后进入“复位/校准命令 + 串口测试菜单 + Flash 日志读取方案”阶段。

## 测试精度等级

- 当前阶段：非精准确认测试。
- 目的：确认 INS 方向正确、误差大致可接受、是否值得进入下一阶段准备。
- 不用于：最终标定、算法参数精修、导航精度承诺。
- 当前条件：手推、场地、尺量和路径误差都会影响结果，因此不能用当前数据直接修改轮径、轮距或左右轮 counts/rev。
- 切换条件：只有用户明确说“开始精准测试”时，才另开精准测试流程。

## 固定测试方式

每一组测试都按同样流程执行：

1. 上电后等待 `[INS] Ready: yaw zero=...`。
2. 静止 3 秒，确认 `X/Y/V/W` 接近 0。
3. 用尺子、地面胶带或标记线确定起点和终点。
4. 手推尽量慢、直、匀速，避免打滑、急停、突然转向。
5. 每组测试结束后停车 2 秒。
6. 只记录停止稳定后的最后 3 行 `[INS]`。

## 测试项目

### 1m 直线测试

- 距离：1.000m。
- 次数：3 次。
- 通过标准：`X` 误差小于 0.05m，`Y` 偏移小于 0.03m。

### 2m 直线测试

- 距离：2.000m。
- 次数：3 次。
- 通过标准：`X` 误差小于 0.10m，`Y` 偏移小于 0.06m。

### 60cm 正方形回原点测试

- 路径：边长约 0.600m 的正方形，最终回到起点。
- 次数：3 次。
- 通过标准：最终 `X/Y` 误差均小于 0.08m。

### 原地右转 90 度测试

- 动作：原地右转 90 度。
- 次数：3 次。
- 通过标准：`YAW` 在 -90° ± 8° 内。
- 说明：当前坐标定义接受“右转 yaw 为负数”。

## 判定规则

- 如果全部通过：进入下一阶段，开始做“惯导复位/校准命令 + 更清晰串口测试菜单 + Flash 日志读取方案”。
- 如果直线误差持续超标：先不要进入导航，优先修正轮径或左右轮 counts/rev。
- 如果正方形回原点误差大但直线正常：优先修正轮距 `INS_WHEEL_BASE_M`。
- 如果 90 度 yaw 误差大：优先处理 IMU yaw 漂移、yaw 符号或 yaw 零点逻辑。
