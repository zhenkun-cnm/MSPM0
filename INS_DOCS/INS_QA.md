# 惯导问答

## 什么是小车惯导？

在这个项目里，惯导先理解为：小车自己估计“我从起点走到了哪里、现在朝哪个方向”。第一版用轮子编码器算走了多远，用 IMU 姿态角里的 yaw 判断方向。

## yaw 初始化为 0 以后，为什么还要看方向？

yaw 初始化为 0 表示“当前朝向作为起点”。但还要知道小车向左转时 yaw 是增加还是减少。如果方向反了，程序会把左转当成右转，地图会镜像。

## M2 只有 985 每圈会不会影响惯导？

不会，只要使用实测标定值。真正会影响惯导的是把 M2 错当成 1040。第一版里 M1 用 1054，M2 用 985，左右轮分别换算距离。

## 为什么需要 Flash 日志？

串口只能看到当前输出，Flash 可以把运行过程保存下来。以后如果直线 1 米走成 0.95 米，我们可以通过日志看是编码器、yaw，还是积分公式的问题。

## 第一版算不算高精度？

第一版是高精度的基础版：先把短距离直线、原地转角、矩形回到起点这些测试做稳。真正房间级长时间稳定，还要继续做轮距修正、左右轮半径修正、yaw 方向和漂移补偿。

## 怎么判断第一版有没有跑对？

先不要急着自动导航。把车放地上，串口看 `[INS]`：

1. 静止 10 秒，`X/Y/V` 基本不动，说明没有明显假脉冲。
2. 向前推 1 米，`X` 接近 1.000，`Y` 接近 0，说明轮径和 counts/rev 大体正确。
3. 原地转 90 度，`YAW` 接近 90 或 -90，说明 yaw 能用；如果符号反了，只改 `INS_IMU_YAW_SIGN`。
4. 走一个矩形回到起点，`X/Y` 离 0 越近，说明整体误差越小。

## 为什么先做位姿估计，不直接做自动导航？

自动导航依赖“我在哪里”和“我朝哪里”。如果位姿估计本身不稳，导航控制会越修越偏。第一阶段先把 `x/y/yaw` 做可信，再进入路径跟踪、PID 或闭环控制。
